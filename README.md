# Cahier de français 🇫🇷

Личный сайт для ежедневной подготовки к DELF B2: слова с интервальным повторением, слово и фраза дня, грамматика, диктанты, аудирование, чтение, письмо, говорение, трекер успеха, план до экзамена.

Сайт статический (HTML + CSS + JS), без серверов и аккаунтов. Работает офлайн, шрифты лежат внутри (без Google).

## Как выложить на GitHub Pages (10 минут)

1. Зарегистрируйся на github.com (если ещё нет аккаунта).
2. Нажми **New repository**. Назови, например, `francais`. Поставь **Public**. Нажми **Create repository**.
3. На странице репозитория нажми **uploading an existing file**.
4. Распакуй архив и перетащи в окно **всё содержимое папки** (папки `css`, `js`, `fonts`, `icons`, файлы `index.html`, `sw.js`, `manifest.webmanifest`, `.nojekyll`). Важно: `index.html` должен лежать в корне репозитория, а не внутри вложенной папки.
   - Файл `.nojekyll` начинается с точки и может быть скрыт в проводнике. Включи показ скрытых файлов (Mac: `Cmd+Shift+.`, Windows: Вид → Показать скрытые элементы). Если не получится, сайт всё равно заработает, это не критично.
   - GitHub в браузере принимает до 100 файлов за раз. Если файлов больше, загрузи в два-три захода (сначала `js`, потом остальное).
5. Нажми **Commit changes**.
6. Открой **Settings → Pages**. В разделе *Build and deployment* выбери **Deploy from a branch**, ветку **main**, папку **/ (root)**, нажми **Save**.
7. Через 1–2 минуты сверху появится адрес вида `https://ТВОЙ-ЛОГИН.github.io/francais/`. Это и есть твой сайт.

## Как поставить на телефон как приложение

- **iPhone (Safari):** открыть сайт → «Поделиться» → «На экран Домой».
- **Android (Chrome):** меню ⋮ → «Установить приложение» / «Добавить на главный экран».

После этого сайт открывается как приложение и работает без интернета.

## Что важно знать

- **Прогресс хранится в браузере.** Если очистить данные сайта или сменить устройство, прогресс пропадёт. Раз в неделю заходи в **Ещё → Резервная копия → Скачать копию** и сохраняй файл в облако. На другом устройстве копию можно загрузить там же.
- Один и тот же адрес на телефоне и на компьютере — это два отдельных хранилища. Переноси прогресс через копию.
- **Дата экзамена** по умолчанию 13.03.2027. Это ориентир. Точные даты весенней сессии в Москве смотри на сайте Institut français и поменяй их в **Ещё → Настройки**. План подстроится сам. Запись на экзамен делай заранее: места заканчиваются.
- **Озвучка** использует голоса твоего браузера и телефона. Если французского голоса нет, скачай его в настройках системы (на Android: «Синтез речи», на iPhone: «Универсальный доступ → Речевой контент → Голоса»).
- **Запись голоса** (раздел «Говорение») работает только по https. На GitHub Pages это так. Откроешь файл с диска — микрофон может не работать.
- Тексты для аудирования и чтения — учебные, цифры в них иллюстративные. Официальные образцы заданий ищи по ссылкам в разделе «Ресурсы».
- Красная ручка в разделе «Письмо» — автоматическая проверка (длина, связки, типичные ошибки). Она не заменит живого преподавателя. Раз в 2–3 недели покажи текст репетитору или носителю.

## Как менять содержимое

Все данные лежат в папке `js/data/`:

| Файл | Что внутри |
|---|---|
| `vocab.js` | темы со словами (строки вида `французский\|русский`) |
| `phrases.js` | клише для письма и устной части |
| `grammar_a.js`, `grammar_b.js` | уроки грамматики и упражнения |
| `dictation.js`, `listening.js`, `reading.js` | диктанты, аудирование, чтение |
| `prompts.js`, `topics.js` | темы для письма и говорения |
| `wotd.js` | слова дня |
| `resources.js` | ссылки |

Свои слова проще всего добавлять прямо на сайте: **Слова → Добавить слово**.

**После любых правок файлов на GitHub** открой `sw.js` и увеличь число в строке `const VERSION = 'cahier-v1';` (например, `cahier-v2`). Иначе телефон может ещё какое-то время показывать старую версию. Если новый файл добавил, впиши его в список `CORE`.

## Как пользоваться (коротко)

1. Открой вкладку **Сегодня**. Там всё на день: слова, одно-два задания, слово и фраза дня.
2. Нет сил? Включи режим «минимум»: только повторение слов и одно задание, около 10 минут.
3. Воскресенье — день отдыха: только итоги недели. Серия при этом не прерывается.
4. Пропуски не страшны: «джокеры» спасают серию. Просроченные слова не копятся лавиной, сайт сам ограничивает дневную порцию.
5. Незнакомые слова оценивай честно: «Снова / Трудно / Хорошо / Легко». Алгоритм подстроит интервалы.
